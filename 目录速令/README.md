# 目录速令 · uTools 插件

> 在资源管理器里选中文件夹 / 文件（或让焦点停在文件夹窗口），呼出 **uTools 超级面板**，
> 点一下命令名 —— **直接执行，不弹任何窗口**。

每条命令在超级面板里都是独立的一项，可以自建任意多条，每条都能配自己的图标
（`png / jpg / jpeg / ico` 图片文件，或**直接从任意 exe 中提取图标**）。

- 想直接用 → 本文档。
- 想改代码 / 了解内部实现 → 见 [`DEVELOP.md`](./DEVELOP.md)。

---

## 一、它是怎么工作的

```
┌─ 你在资源管理器里选中文件夹 / 文件 ───────────────────┐
│                                                      │
│   uTools 超级面板  ⇢  显示「VS Code 打开」            │
│                      显示「在此打开 CMD」             │
│                      显示「复制路径」                 │
│                            ↓ 点一下                   │
│   插件拿到你选中的路径 → 替换掉命令里的 {path} 之类的变量 │
│                            ↓                          │
│   程序起来了，uTools 全程没有出现窗口                   │
└──────────────────────────────────────────────────────┘
```

关键就两点：

1. 每条自定义命令的**每一种匹配方式**都是超级面板里的一个**独立入口** ——
   在面板里能一眼看到「VS Code 打开」「在此打开 CMD」，而不是先点插件名再选一次。
2. 点了之后**不弹窗**，命令在后台直接跑起来。

插件本身**只有一个界面**：命令管理（在 uTools 里搜 `目录速令` 打开）。
配好之后日常使用完全不经过它。

## 二、快速开始

1. 打开 uTools 开发者工具 → **接入开发** → 选择本目录（`plugin.json` 所在目录）。
2. 在 uTools 搜索框输入 **`目录速令`** 进入管理界面（这是**唯一**会开窗口的地方）。
   首次进入会自动写入几条示例命令，并把它们注册进超级面板。
3. 打开任意文件夹 → 选中它（或选中里面的文件）→ 呼出超级面板 → 点命令名，直接跑。

> **注意**：命令是在插件被加载时注册到超级面板的。全新安装后请先打开一次「目录速令」
> 让插件跑起来；之后每次增删改命令都会自动重新注册。

## 三、界面总览

管理界面从上到下就是三块：

```
┌──────────────────────────────────────────────────────┐
│  [🔍 搜索名称 / 程序 / 参数 / 分类…]   [多选] [ 新建 ] │   ← 搜索在左，多选 / 新建在右
├──────────────────────────────────────────────────────┤
│  [全部 6] [开发 1] [系统 2] [终端 3]     全部|启用|停用 │   ← 分类筛选（左）+ 状态筛选（右）
├──────────────────────────────────────────────────────┤
│  ☐ 全选  反选  已选 3 项   [停用] [启用] [删除]        │   ← 只有开了「多选」才出现
├──────────────────────────────────────────────────────┤
│  ⠿  VS Code 打开            [编辑] [停用] [删除]      │   ← ⠿ 是拖拽手柄
│      code {qpath}                                    │   ← 副标题：程序名 + 参数
│  ⠿  在此打开 CMD            [编辑] [停用] [删除]      │
└──────────────────────────────────────────────────────┘
```

- **搜索**：匹配名称 / 程序 / 参数 / 工作目录 / 分类 / 内置动作名 / 匹配方式。
- **分类标签**：`全部` + 每个分类 + `未分类`，各自带数量；搜索后没命中的分类会变灰。
- **状态筛选**（右边的 `全部 | 启用 | 停用`）：只看启用的或只看停用的。
- **新建**：切到编辑页新增一条命令（见第四节）。
- **编辑页是整页的，不是弹窗**：点「新建」或某行的「编辑」会**整屏切换**过去，
  左上角 **← 返回** 或按 **Esc** 回列表。
- **多选**：点一下进入多选模式，列表每行前面才会出现勾选框（见第五节）。
- **每行操作**：`编辑` / `停用`（已停用时显示为高亮的 `启用`）/ `删除`（点两下确认，第二下才真删）。
  **单击整行不会有任何反应** —— 想改就点行尾的 `编辑`，避免手滑切到编辑页。
- **行副标题**是「程序名 + 参数」，**程序前面的目录会省略**（`C:\Tools\bin\run.exe -x`
  只显示 `run.exe -x`）；鼠标悬停可以看到完整命令。
- **拖拽排序**：抓住每行最左边的 **⠿ 手柄**上下拖，松手即改顺序 ——
  顺序就是超级面板里的显示顺序，改完立刻生效。（多选模式下没有手柄，见第五节。）

## 四、配置一条命令

点 **新建** 切到编辑页。字段顺序是：

```
起始模板（只有「新建」时出现）
图标  →  名称 + 分类标签  →  类型  →  匹配方式  →  匹配条件卡
      →  命令 / 程序  →  命令参数  →  复制变量  →  动作（仅内置动作）
```

### 4.1 从模板开始（新建时）

新建时，编辑页最上面有一行**起始模板**，默认选中 **空模板**：

| 模板 | 说明 |
| --- | --- |
| 空模板 | 什么都不填，从零开始（默认） |
| VS Code 打开 | `code {qpath}`，匹配文件 + 文件夹 |
| CMD 打开 | `cmd /k cd /d {qpath}`，匹配文件夹窗口 |
| PowerShell 打开 | `powershell -NoExit -Command "Set-Location …"`，匹配文件夹窗口 |
| Windows Terminal | `wt -d {qpath}`，匹配文件夹 + 文件夹窗口 |
| Git Bash Here | `git-bash.exe --cd={qpath}`，匹配文件夹 |
| Everything 搜索此目录 | `Everything.exe -path {qpath}`，匹配文件夹 |
| 复制路径 / 用默认程序打开 / 资源管理器中定位 | 内置动作 |
| 只匹配图片文件 / 只匹配文档 | 带好扩展名过滤的内置动作 |

点一个模板，名称、分类标签、命令、匹配方式、命令参数会**一次填好**，
之后照常改就行。点回「空模板」会把表单清空重来。

> 编辑**已有**命令时不会出现这一行 —— 模板只用于「从零开始」的那一步。

### 4.2 匹配方式（可多选）

三种匹配方式，**可以同时勾选**：**文件 → 文件夹 → 文件夹窗口**。

| 匹配方式 | 什么时候出现 |
| --- | --- |
| **文件** | 选中文件时 |
| **文件夹** | 选中文件夹时 |
| **文件夹窗口** | 焦点停在文件夹窗口 / 桌面时（含文件夹空白处） |

每勾一种，就在超级面板里多注册一条独立入口，编辑页里也会**各多出一张**
「匹配条件」卡和「命令参数」卡，彼此完全独立。

> 新建时**默认一项都不勾**，勾选框右边会跟着一行红字提醒「至少选中一项」——
> 因为一种都不勾的话，这条命令会彻底不出现在超级面板里，保存时也会被拦下。
> 把鼠标停在勾选框上可以看到它对应的使用场景。

### 4.3 匹配条件

匹配方式决定「什么时候出现」，匹配条件决定「什么样的目标才算命中」。

**文件 / 文件夹**（两者结构一样，各存一份）—— 卡片里排成两行：

```
最少选中个数 | 最多选中个数 | 名称最少字符数 | 名称最多字符数
名称匹配 ▾   | 扩展名 / 名称正则（跟着上一项切换）
```

| 参数 | 说明 |
| --- | --- |
| 最少选中个数 | **选中了几项**的下限，留空即不限 |
| 最多选中个数 | **选中了几项**的上限，留空即不限 |
| 名称最少字符数 | **单个名称有多长**的下限（**含后缀**，`photo.jpg` = 9 个字符） |
| 名称最多字符数 | 单个名称长度的上限 |
| 名称匹配 | 「**不限制** / **扩展名** / **正则**」三选一 |
| 扩展名 | 配合「扩展名」，逗号分隔，如 `png, jpg, .PNG`（自动去点、去重、保序） |
| 名称正则 | 配合「正则」，对**含后缀的完整名称**匹配。填 `\.(jpg|png)$` 即可（自动补成 `/…/i`） |

> ⚠️ **「个数」和「长度」是两回事**（这是最容易混的一处）：
> - `最少 / 最多选中个数` 管的是「你选了 3 个还是 30 个文件」。
> - `名称最少 / 最多字符数` 管的是「**单个**文件名有多长」。
> - 两组可以同时填，互不干扰。例如「名称 3~24 字符 + 扩展名 png/jpg」，
>   会同时要求「名字长度在 3 到 24 之间」和「后缀是 png 或 jpg」。
>
> 💡 「名称匹配」选「不限制」时，右边那个条件输入框会整块隐藏，
> 所以「扩展名 / 正则」共用同一个位置，不会各占一行。

**文件夹窗口**：

| 参数 | 说明 |
| --- | --- |
| 窗口标题正则匹配 | 对窗口标题做正则匹配，**选填** —— 留空即所有文件夹窗口都命中 |

> 比如填 `^D:\\` 就只在 D 盘的文件夹窗口里出现。

### 4.4 命令参数（按匹配方式各一份，可「跟随」）

**命令参数** = 参数 + 工作目录，在编辑器里同样**按匹配方式各一张卡片**。

多数情况下三种场景的参数是一样的，这时不用抄三遍 —— 在卡片右上角的「参数来源」里
选 **跟随「文件夹」**，这张卡片就会**收起参数框**，只留一行
「参数与「文件夹」保持一致，请到那张卡片里修改」，并**始终等于**目标卡片的值：
改目标卡片，跟随方立刻同步。

- 跟随只在**目标模式也被勾选**时才有意义；取消勾选目标，跟随方回到自己的参数。
- 互相跟随形成死循环会被拦下并提示，不会写进配置。
- 选中文件夹时和选中文件时可以传**完全不同**的参数。

| 场景 | 典型参数 |
| --- | --- |
| 文件 | `{qpath}` |
| 文件夹 | `{qpath}` |
| 文件夹窗口 | 留空，或 `{path}`（窗口模式下取的是该窗口所在文件夹） |

> ⚠️ `{qpath}` / `{qpaths}` **本身已经带双引号**，模板里不要再套一层 ——
> 写成 `"{qpath}"` 会拼出 `""D:\a""`。想要不带引号的裸路径用 `{path}`，外面自己包引号。

### 4.5 变量占位符

`命令 / 程序` 和**每一张命令参数卡**里都能用。编辑器里每个变量旁边都写了用途，
**点一下即把占位符复制到剪贴板**，再到要用的输入框里粘贴 —— 不挑焦点，想贴哪格贴哪格。

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{path}` | 第一个文件夹 / 文件的完整路径（**未加引号**） | `D:\Project\demo` |
| `{qpath}` | 已加双引号的路径，**路径含空格时用它** | `"D:\My Project"` |
| `{name}` | 第一个的名称（**含后缀**） | `demo` / `photo.jpg` |
| `{parent}` | 上级目录 | `D:\Project` |
| `{drive}` | 盘符 / 根 | `D:` |
| `{paths}` | 全部选中路径 | `D:\a D:\b` |
| `{qpaths}` | 全部选中路径，各自加引号 | `"D:\a" "D:\b"` |
| `{names}` | 全部选中项的名称（含后缀） | `a.txt b.log` |
| `{ts}` | 当前时间戳（毫秒） | `1730000000000` |
| `{date}` | 当前日期 | `2026-10-01` |

#### 列表变量可以自定分隔符

`{paths}` `{qpaths}` `{names}` 这三个是**列表变量** —— 选中多项时要把多个值拼成一串。
默认用**空格**分隔（`{qpaths}` 另外会给每一项都加双引号），也可以在冒号后**指定分隔符**：

| 写法 | 结果 |
| --- | --- |
| `{paths}` | `D:\a D:\b`（默认空格） |
| `{paths:,}` | `D:\a,D:\b` |
| `{paths: \| }` | `D:\a \| D:\b`（分隔符可以是任意字面文本） |
| `{paths:}` | `D:\aD:\b`（分隔符为空 = 直接拼接） |
| `{qpaths:, }` | `"D:\a", "D:\b"`（**逗号 + 空格，且每项自带引号** —— 传给命令行最常用的形式） |
| `{names:\n}` | `a.txt` 换行 `b.log`（`\n` 换行、`\t` 制表、`\r` 回车、`\\` 反斜杠） |

- 分隔符里**不能包含 `}`**（那是占位符的结束符）。
- 非列表变量（如 `{name}`）后面跟冒号没有意义，会被忽略。

> 实用组合：命令填 `cmd`，参数填 `-c "type {qpaths:, }"`，
> 选中一堆文件时就能一次性拼成参数列表。
> 分隔符记不住没关系：编辑页「复制变量」面板下面有一张**分隔符示例表**
> （`docs/varsep.png`），每行就是一个写法 + 替换结果，**点一下整条写法复制走**，
> 粘进参数框就能用 —— 包括「想要空格分隔」：不写冒号就是空格，写 `{paths: }` 也一样。

### 4.6 图标

| 来源 | 说明 |
| --- | --- |
| 默认（自动识别） | 从命令第一个 token 推导：完整路径查真实图标，命令名去 `PATH` 里找 |
| 图片文件 png / jpg / jpeg / ico | 选一个图片文件（svg / webp / bmp / gif 也支持） |
| 从 EXE 提取图标 | 选任意 `exe`（也支持 `lnk` / `bat` / `cmd`），取系统图标 |
| 文件夹系统图标 | 系统文件夹图标 |
| 按扩展名（如 .txt） | 某个扩展名的系统关联图标 |
| 自定义 base64 | 直接粘 `data:image/...` |

图标直接显示在超级面板上。

### 4.7 类型：执行命令 / 内置动作

- **执行命令**：填「命令 / 程序」+「命令参数」。
- **内置动作**：不用写命令，从下拉里选一个现成的：

  复制路径 / 复制带双引号的路径 / 复制名称（含后缀）/ 用系统默认方式打开 /
  在资源管理器中定位 / 复制到剪贴板（文件）。

  内置动作执行完会弹一条**系统通知**告诉你结果（因为它没有界面可以反馈）。

### 4.8 试运行 / 参数测试

底栏有两条互不干扰的验证入口：

| 按钮 | 做什么 | 什么时候用 |
| --- | --- | --- |
| **试运行** | 选一个测试文件夹，**真的跑一遍** | 确认程序能被拉起来 |
| **参数测试** | **不执行**，把变量替换后的**完整命令行**摊开给你看 | 确认拼出来的命令对不对 |

**参数测试**会在底栏上方展开一条面板：

- 顶部是「测试路径」：**每行一个路径**，可以混着填文件和文件夹。
  点「**加目录**」/「**加文件**」可以一次挑多个追加进去，「**清空**」一键清掉；
  默认取资源管理器当前打开的目录。改动会**实时**重新计算。
- 选中多项时，列表变量（`{paths}` `{qpaths}` `{names}`）才会真正展开成列表 ——
  所以要测「多选」的效果就多填几行。
- 下面按匹配方式**分行**列出：每行 = 模式名 + 替换后的完整命令（含工作目录）。
  三种匹配方式可以各配一套参数，所以各出一行，一眼就能看出差别。
- **点任意一行即复制那条完整命令**，方便粘到 cmd / 终端里核对。
- 改表单（命令、参数、匹配方式）时面板会跟着刷新，不用点第二次。

内置动作不产生命令行，参数测试会提示「内置动作不产生命令行」。

## 五、启用 / 停用 / 多选

**停用**一条命令 = 它不再出现在超级面板，但配置完整保留（随时能开回来）。

### 5.1 单条切换

点那一行操作区中间那颗按钮：启用时显示 **停用**，停用后变成 **启用**（并高亮成主色）。
停用的行会整行变灰 —— 那颗 **启用** 就是唯一的「点这里恢复」出口，所以刻意做成亮点。

> 停用的命令**不额外挂标签**：整行变灰 + 按钮变成高亮的「启用」已经说明了一切。

### 5.2 多选模式

列表每行前面的勾选框**默认不显示**。点右上角的 **多选** 才进入多选模式
（按钮会变成实心高亮），这时才会出现勾选框和批量操作条：

| 控件 | 作用 |
| --- | --- |
| `全选` | 选中**当前可见的**所有行 |
| `反选` | 把当前可见行的勾选状态**反过来**（勾上的取消、没勾的勾上） |
| `已选 N 项` | 当前真实勾选总数 |
| `停用` / `启用` | 批量切换启用状态 |
| `删除` | 批量删除（点一下变成「确认删除 N 项?」，再点一下才真删） |

- 「全选」和「反选」都只作用于**当前可见的行**（搜索 + 分类 + 状态筛选之后剩下的），
  所以「筛出某个分类 → 全选 → 停用」是最顺手的批量用法。
- 勾选状态在**搜索 / 切分类 / 切状态后不会丢**；批量按钮作用于**所有已勾选项**，
  包括当前被筛掉、看不见的那些 —— 计数显示的 `已选 N 项` 是真实总数。
- 关掉多选模式会**一并清空勾选**（否则会留下一批看不见的「已选」）。

多选模式下的鼠标操作和平时不一样：

| 手势 | 效果 |
| --- | --- |
| 单击某一行 | 切换这一行的勾选 |
| **按住鼠标在列表上拉一个框** | 框到的行**实时高亮**，松手后全部勾上（框选） |
| 拖拽手柄 | 不显示 —— **多选模式下不能排序**，先关掉多选再拖 |

> 为什么要换掉拖拽：拖拽排序和「拉框选行」是同一个手势（按住 + 移动），
> 同时开着会互相打架，所以多选模式下把排序整个让给了框选。
> 框选只做**加选**；想去掉某几行，单击它们即可。

---

## 六、排序

每行最左边有一个 **⠿ 拖拽手柄**，按住它上下拖就能改顺序，松手立即生效。
顺序就是命令在**超级面板里的显示顺序**。

> 松手落在哪里以目标行的**中线**为准：上半区插到它前面，下半区插到它后面。
> 拖动时会出现一条主色横线，告诉你松手会落在哪。
>
> **多选模式下没有手柄、也不能排序** —— 那个拖动手势被框选占用了（见 5.2）。

## 七、常见问题

**Q：超级面板里找不到我的命令？**
A：依次检查 ——
① 是否至少打开过一次「目录速令」（命令需要插件加载后才注册）；
② 匹配方式是否和当前场景对得上（选文件夹用「文件夹」，选文件用「文件」，
焦点在文件夹窗口空白处或桌面用「文件夹窗口」）；
③ 匹配条件是不是太严 —— 比如给文件夹设了「扩展名 png」，那选中文件夹时永远不命中；
或者「最少选中个数」填得比实际选中个数还大；
或者「名称最少字符数」比文件名还长（注意是**含后缀**的长度）；
④ 这条命令是不是被停用了（把右上角的状态筛选切到「停用」就能一眼看出来）；
⑤ uTools 设置 → 超级面板，确认已启用、且本插件没有被禁用。

**Q：为什么点列表里的某一项没反应？**
A：这是故意的 —— 单击整行不会做任何事，怕手滑就把编辑页顶出来。
要改这条命令，点它右边的 **编辑**。

**Q：拖拽手柄怎么不见了？**
A：多选模式下不显示手柄，那个拖动手势改成了**拉框选行**。
关掉右上角的 **多选** 就回来了。

**Q：想临时关掉某条命令，但不想删掉它？**
A：点那一行中间的 **停用**，一下就好。它会从超级面板消失，配置仍然保留，
整行变灰、按钮变成高亮的 **启用**，再点一下就能开回来。

**Q：想一次性关掉好几条命令？**
A：点 **多选** 进入多选模式 → 勾选（或用 **全选** / **反选**）→ 点批量条上的 **停用**。
配合筛选更好用：先点某个分类、或把状态切到「启用」→ 点「全选」→ 点「停用」。

**Q：能一次删掉好几条吗？**
A：可以。进多选模式 → 勾好 → 点 **删除** → 再点一次确认。
「删除」对**所有已勾选项**生效，包括当前被筛掉、看不见的那些，所以确认提示里
会写明确切的条数（`确认删除 N 项?`）。

**Q：怎么调整命令在超级面板里的顺序？**
A：拖每行最左边的 **⠿ 手柄**，松手即生效。手柄本身不响应点击 —— 那是拖拽区。
注意**多选模式下不能排序**（手柄会消失），先关掉多选再拖。

**Q：勾选框怎么不见了？**
A：勾选框只属于**多选模式**，默认是隐藏的。点右上角的 **多选** 才会出现，
同时出现批量操作条；再点一下退出（退出时勾选会被清空）。

**Q：新建时那行「起始模板」是什么？我不想用模板。**
A：默认就是**空模板**，什么都不填。想要现成的就点一个，表单会被一次填好，
之后照常改。编辑已有命令时不会出现这行。

**Q：一条命令同时勾了「文件夹」和「文件夹窗口」，会重复吗？**
A：不会 —— 它们本来就该在两个场景里各出现一次。
只有在同一个场景里**同时选中文件夹和文件**时（多选、混着选），
「文件」和「文件夹」两条可能一起命中，面板里会出现两条同名条目 ——
把其中一条的名称改得可区分即可。

**Q：「跟随」和直接填一样的值有什么区别？**
A：跟随是**活的**：目标卡片的命令参数一改，跟随方立刻同步，并且它的参数框会**收起**，
避免两边慢慢改歪、也省编辑页的地方。存盘时会把值写实，所以运行时并不依赖这个关系。
「跟随」只作用于**命令参数**；「匹配条件」是各模式自己的筛选条件，不参与跟随。

**Q：「最少选中个数」和「名称最少字符数」到底哪个是哪个？**
A：一个是「选了**几个**」，一个是「名字**多长**」。
名称字符数是**单个**文件名（**含后缀**，`photo.jpg` = 9）的长度。
两组可以同时填，互不干扰。

**Q：选中多个文件时，怎么把它们的路径拼成一行给命令用？**
A：用列表变量 + 自定分隔符，比如 `-c "type {qpaths:, }"` 会得到
`"D:\a", "D:\b"`（逗号加空格、每项自带引号）。`{names:,}` 用名称、`{names:\n}` 换行。
分隔符写在冒号后面，**不写就默认空格**（写 `{paths: }` 显式给空格也行）。
编辑页「复制变量」面板下面的分隔符示例表把这些写法全列出来了，点一下复制就能用。

**Q：同一个命令，选中文件夹和选中文件想传不同参数？**
A：在「命令参数」区域里分别填那张卡片即可，
例如文件夹传 `{qpath}`、文件传 `--file {qpath}`。
不填的那套就是空的（空参数 = 只跑程序、不带参数）。

**Q：编辑页里的「删除」怎么不见了？**
A：删除入口统一收回到**列表**了 —— 点那一行右边的「删除」（点两下确认），
或者进多选模式批量删。编辑页底栏只留「试运行 / 参数测试 / 取消 / 保存」。

**Q：想看看命令到底会被拼成什么样，但又不想真跑？**
A：用编辑页底栏的 **参数测试**。它不执行任何东西：在「测试路径」里**每行填一个路径**
（点「加目录」/「加文件」可以一次挑多个，文件和文件夹可以混着填），
就把变量替换后的完整命令行按匹配方式分行列出来；点其中一行还能直接复制。
想测「多选」就把多行路径都填上，列表变量会展开成列表。「试运行」才是真跑一遍。

**Q：执行后没有任何提示，是不是没生效？**
A：外部程序自己会出界面（VS Code、终端等）。内置动作（复制路径之类）没有界面，
会通过系统通知告诉你结果。想确认命令本身对不对，先用 **参数测试** 看拼出来的命令行，
再用 **试运行** 真跑一遍。

**Q：路径带空格时命令报错？**
A：把 `{path}` 换成 `{qpath}`（它自带双引号），或写成 `"{path}"`。
注意别写成 `"{qpath}"` —— 那会变成两层引号。

**Q：执行 cmd / PowerShell 看不到控制台窗口？**
A：正常情况下**不用设置** —— 插件会自动识别 `cmd` / `powershell` / `pwsh` / `wt` /
`wsl` / `git-bash` 这类**自己会开控制台的程序**并让它的窗口显示出来。
如果你的命令写成 `start cmd /k …` 这种**用别的程序把终端拉起来**的形式，
最外层的 `start` 不是控制台程序，就会被静默 —— 这时直接写 `cmd /k …` 即可。

**Q：从 exe 提取的图标是空白的？**
A：部分系统组件（如 `wt.exe`）本身没有图标资源。指向该软件安装目录里的主程序 exe，
或者直接选一张 png。

**Q：能给它配全局快捷键吗？**
A：可以。在 uTools 设置里给对应指令绑定快捷键即可。

**Q：命令存在哪？**
A：uTools 本地数据库，每个设备独立，不上传。

**Q：升级插件后，以前配的命令还在吗？**
A：在。历史上有过两次结构调整，都会在首次加载时自动迁移并立即落盘
（幂等，重复加载不会重复改动）：早期用 `trigger` 单值 → 现在的 `matches` 三态多选；
「参数 / 工作目录」原本在顶层放一份 → 现在按匹配方式各一份。
具体见 [`DEVELOP.md`](./DEVELOP.md) 的「数据迁移」一节。

**Q：想换配色？**
A：所有颜色都是 `assets/style.css` 顶部的主题令牌，暗色与亮色分别定义在
`html[data-theme="dark"]` 与 `html[data-theme="light"]` 下，改一处全局生效。
细节见 [`DEVELOP.md`](./DEVELOP.md) 的「视觉规范」一节。
